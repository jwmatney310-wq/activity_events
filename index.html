Selectors Used

$("#click-button")
The # selects the element with the ID click-button. Its click event changes the button's text.
$(".double-button")
The dot selects elements with the class double-button. Its double-click event toggles a CSS class and changes the button's text.
$("p.hover-box")
This selects paragraph elements with the class hover-box. The mouseenter and mouseleave events change the paragraph's style and text as the pointer enters and leaves.
